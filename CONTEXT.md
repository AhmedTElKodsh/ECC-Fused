# ECC-Fusion Context

ECC-Fusion is a planned agentic development library that keeps ECC as the base platform while adding governed Short Path and Regular Path workflows.

Current implementation status: initial prompt, routing, manifest, schema, `/ecc-help`, and documentation scaffold.

Primary constraints:

- Preserve ECC compatibility.
- Keep skills concise and categorized.
- Prefer explicit route notes over implicit routing.
- Emit Transition Notices instead of inventing missing artifacts.
- Gate Ralph to bounded low-risk execution loops only.
