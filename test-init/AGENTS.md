# Agent Instructions

Welcome, AI Developer Agent! This file outlines the conventions, rules, and expectations for working in the **ECC-Fused** repository.

## Agent skills

### Issue tracker

Issues and PRDs live as GitHub issues. We use the `gh` CLI for all operations. See `docs/agents/issue-tracker.md`.

### Triage labels

We use the canonical triage label vocabulary to manage issue state. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository. Domain terms are in `CONTEXT.md` and ADRs live in `docs/adr/`. See `docs/agents/domain.md`.
