# Review & Release Skills Map

This phase ensures quality, security, and learning before handing off the completed feature.

| Skill Name | Description | Adapted Source Library |
|---|---|---|
| `review-oss-output` | Senior-level review of work generated by smaller/OSS models. | gstack |
| `security-review` | Audits the code for standard vulnerabilities. | gstack |
| `ship-release` | Prepares the release checklist and finalizes deployment artifacts. | gstack |
| `handoff` | Generates a clean state summary to hand the session back to the user. | Matt Pocock's Skills |
| `retro-learn` | Documents lessons learned and updates the implementation log. | BMAD-METHOD |
