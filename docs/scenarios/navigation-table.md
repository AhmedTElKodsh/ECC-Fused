# Scenario-Based Navigation

If you're not sure which skill or command to use, find your scenario below.

| If you want to... | Then try this command... | Which runs this skill... |
| :--- | :--- | :--- |
| **Get started but don't know how** | `/ecc-help` | `ecc-help` |
| **Draft a Product Requirements Document (PRD)** | `/ecc-spec` | `write-spec` |
| **Discuss architecture and design decisions** | `/ecc-plan` | `architecture-plan` |
| **Break work down into manageable packets** | `/ecc-packetize` | `create-work-packets` |
| **Implement a work packet** | `/ecc-execute-packet` | `implement-work-packet` |
| **Review output against requirements** | `/ecc-verify` | `verify-work` |
| **Check code for security issues** | `/ecc-security-review` | `security-review` |
| **Hand off completed work** | `/ecc-ship` | `ship-release` |
| **Automate a repetitive, low-risk task** | `/ecc-ralph-run` | `ralph-loop` |

## Why This Exists

This document translates the internal 13 skill categories into plain-English user goals. It exists to guide you smoothly without overwhelming bureaucracy.
